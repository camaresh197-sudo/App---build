# Hula Vaquero: Sky Ride

A Godot 4.6 game (desktop, Android, and a web wrapper) starring a procedurally animated
3D vaquero, with a Python/Blender character pipeline and a sample-bank mariachi soundtrack.

**Start with [`AGENTS.md`](AGENTS.md)** — it is the repo map, command reference, and the
list of binary/asset folders that should not be scanned.

```powershell
powershell -File .\build.ps1   # smoke test, import, update packs
```
